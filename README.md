# Coding Notes Website

A very simple site displaying notes I have taken while learning about development.
It is separated into various pages and uses HTML CSS and Vanilla JS (I started it when that was all I knew). I hope to refactor it someday.

🔗 **Live Site:** https://scrimba-code-notes.netlify.app/

## 🚀 Features

- Notes on various languages (and then some) sectioned off in separate pages

- A search bar (could use some love, just uses regex to match)

- A fun UI, which may not be a "feature" but it is the meat and potatoes behind this site

- Each subject includes various sections

    - General Notes

    - Valuable Resources

    - Personal Preferences

    - Relevant Defintions

    - Questions + their answers

- Valuable resources for each subject

- Personal preferences for eachs

## 🚀 Deployment

This project is deployed using **Netlify**.

## # Deploy Your Own
1. Fork this repository
2. Update it with your own notes
3. Go to https://netlify.com
4. Click **Add New Site → Import from Git**
5. Select your GitHub repo
6. Set build command:
   ```
   npm run build
   ```
6. Set publish directory:
   ```
   dist
   ```
7. Click **Deploy**
